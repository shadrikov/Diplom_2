# Diplom_2 Автотесты API для учебного сервиса Stellar Burgers

Проект автотестов для учебного API Stellar Burgers

## Стек
- Python
- requests
- pytest
- allure-pytest
- Faker

## Установка
1. `python -m venv .venv`
2. Активировать окружение
3. `pip install -r requirements.txt`

## Запуск тестов
`pytest --alluredir=allure-results`

## Отчёт Allure
`allure serve allure-results`

## Покрытие
- создание уникального пользователя
- попытка создания пользователя, который уже зарегистрирован
- попытка создания пользователя и без заполнения одного из обязательных полей
- вход под существующим пользователем
- попытка входа с неверным логином и паролем
- создание заказа с авторизацией
- создание заказа без авторизации
- создание заказа с ингредиентами
- попытка создания заказа без ингредиентов
- попытка создания заказа с неверным хешем ингредиентов
